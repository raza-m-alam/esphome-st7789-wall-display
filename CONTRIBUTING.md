# Contributing

Keep contributions narrowly scoped and testable.

Before submitting a change:

- Do not commit credentials or device-specific local data.
- Preserve a tested hardware profile unless the change explicitly adds or
  modifies that profile.
- State the ESPHome version, board, and display controller used.
- Include automated results and, for runtime behavior, hardware results when
  available.
- Document known limitations and do not claim compatibility with untested
  hardware.
