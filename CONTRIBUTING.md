# Contributing

Keep contributions narrowly scoped and testable.

Before submitting a change:

- Do not include credentials, private network information, personal media,
  or household-specific Home Assistant entities.
- Preserve the tested display profile unless the change explicitly adds a
  separate hardware profile.
- State the ESPHome version used.
- State the exact board and display controller tested.
- Include validation results and known limitations.
- Do not claim compatibility with untested hardware.
